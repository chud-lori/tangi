tangi

A tiny, fast keep-awake tool for macOS & Linux. Keeps your computer awake, your screen on, and you showing as active in Slack — for exactly as long as you want, with a live countdown you can check, extend, and stop from any terminal.

Why tangi

Small enough to forget it's there, real enough to trust it.

🪶Tiny & efficient

A ~36 KB stripped binary with no runtime dependencies on macOS. The daemon sleeps in select() — no polling, near-zero CPU and memory.

🟢Stays online by default

Keeps the system awake, the display on, and — every ~50s — tells the OS you're active so Slack & Teams keep showing you online. No visible cursor moves or keystrokes. Use -s to opt out.

⏱️Live, controllable timer

Check what's left, add more time, or stop early — from any terminal, while it keeps running in the background. Set time in s/m/h/d.

🧹Clean by design

When the timer ends or you run tangi stop, the lock is released, the socket removed, and the daemon exits. Nothing is left running.

Install

A C compiler and make are all you need.

build 
$ git clone https://github.com/your-org/tangi
$ cd tangi
$ ./install.sh         # build + install onto your PATH
✅ Done. Run it from anywhere:
     tangi 1h

# no-sudo option, or remove it again:
$ ./install.sh --user
$ ./install.sh --uninstall

macOS: clang + the system SDK (IOKit / CoreFoundation). Nothing else.
Linux: for the clean fd-based inhibitor, install libsystemd dev headers. Without them, tangi falls back to spawning systemd-inhibit at runtime.

Usage

Five commands. That's the whole surface.

CommandWhat it does
tangi <duration>Start (or reset) — stay awake for the given time.
tangi onStay awake indefinitely, until stopped.
tangi add <duration>Add more time to the current session.
tangi lid <duration>Stay awake even with the lid closed.
tangi statusShow remaining time (also the default with no args).
tangi stopRelease the lock and allow sleep again.

Options

-l, --lidAlso stay awake when the laptop lid is closed.
-s, --system-onlyQuiet mode: only stop the machine sleeping — let the display sleep and leave chat presence alone.
-h, --helpShow help.
-v, --versionShow version and the active backend.

Durations combine d/h/m/s: 45s, 30m, 2h, 1h30m, 1d12h. A bare number means seconds (90 = 90s).

How it works

A pocket-sized daemon plus a thin client, talking over a Unix socket.

  1. You run tangi 30m. It forks a small detached daemon and returns immediately.
  2. The daemon acquires an OS keep-awake lock and listens on a per-user Unix socket ($XDG_RUNTIME_DIR/tangi-<uid>.sock).
  3. status, add, and stop are thin clients that send one line to that socket and print the reply.
  4. When the timer ends — or you run tangi stop — the lock is released, the socket removed, and the daemon exits. The machine sleeps normally again.
